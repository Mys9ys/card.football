# Правила проекта "Эмуляция планеты Земля"

## Общие принципы
- Все изменения кода должны быть согласованы между участниками
- Регулярные резервные копии важных файлов
- Тестирование каждого нового функционала перед интеграцией

## Фронтенд (Vue.js + Canvas)
- Все компоненты должны иметь префикс `Planet` (например, PlanetView, PlanetControls)
- Использовать markRaw() для объектов Three.js чтобы избежать конфликтов с реактивностью Vue
- Максимальный размер текстур: 2048x2048 пикселей
- Анимации должны быть плавными (60 FPS)

## Бэкенд (Python/FastAPI)
- Все API эндпоинты должны начинаться с префикса `/api/v1`
- Использовать Pydantic для валидации данных
- Все модели данных должны быть документированы
- Обязательная обработка ошибок с возвращением HTTP статусов

## База данных (PostgreSQL + Redis)
- PostgreSQL для хранения структурированных данных
- Redis для кэширования и временных данных
- Регулярные бэкапы базы данных
- Использовать миграции для изменения схемы БД

## Система генетики
- Каждый живой объект имеет геном - набор генов, определяющих его свойства
- Гены передаются при размножении с возможностью мутаций
- Геном должен быть сериализуемым для сохранения в БД

## Календарь
- Уменьшенный календарь: 8 месяцев по 20 дней
- Каждый день = 1 игровой цикл
- Время суток: 4 фазы (рассвет, день, закат, ночь)

## Эволюционная ветвь
- Возможность появления новых видов через мутации
- Адаптация видов к окружающей среде
- Выживание наиболее приспособленных

## Социальная система
- Человечки формируют сообщества
- Развитие социальных связей
- Передача знаний между поколениями

## Политическая система
- Формирование лидеров
- Создание правил сообщества
- Конфликты и их разрешение

## Экономическая система
- Обмен ресурсами
- Специализация
- Торговля между сообществами

## Военная система
- Конфликты между сообществами
- Защита территории
- Развитие технологий ведения
