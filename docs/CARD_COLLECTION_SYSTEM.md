# Система сбора и коллекции карт в "Карточный футбол"

## Общее описание

Система сбора карт позволяет игрокам получать новые карты через открытие пакетов, обмениваться дубликатами на валюту и улучшать свои карты. Система состоит из двух основных компонентов:

1. **Система пакетов** - открытие пакетов с картами
2. **Система коллекции** - управление полученными картами

## Типы пакетов

| Тип пакета | Название | Цена (валюта) | Количество карт | Шансы на редкость | Особенности |
|------------|---------|---------------|----------------|-------------------|-------------|
| standard | Стандартный пакет | 100 | 5 | common: 70%, rare: 20%, epic: 8%, legendary: 2% | Основной пакет с разнообразными картами |
| premium | Премиум пакет | 500 | 5 | common: 50%, rare: 30%, epic: 15%, legendary: 5% | Гарантированная эпическая карта |
| legendary | Легендарный пакет | 2000 | 5 | common: 30%, rare: 30%, epic: 25%, legendary: 15% | Гарантированные легендарная и эпическая карты |
| golden_legends | Золотые легенды | 1500 | 5 | common: 0%, rare: 20%, epic: 40%, legendary: 40% | Только нападающие, гарантированная легендарная карта |
| defense_pack | Пакет защиты | 800 | 5 | common: 10%, rare: 30%, epic: 40%, legendary: 20% | Специализированный пакет защиты, гарантированная эпическая карта |
| starter | Стартовый пакет | 0 | 10 | common: 90%, rare: 10%, epic: 0%, legendary: 0% | Бесплатный пакет для новичков, гарантированная редкая карта |

## Механика открытия пакетов

1. Игрок выбирает тип пакета
2. Проверяется наличие достаточного количества валюты
3. Система генерирует карты согласно шансам редкости
4. Применяются правила гарантированных карт:
   - Легендарный пакет: гарантированно содержит хотя бы одну легендарную и одну эпическую карту
   - Премиум пакет: гарантированно содержит хотя бы одну эпическую карту
   - Стартовый пакет: гарантированно содержит хотя бы одну редкую карту
5. Карты добавляются в коллекцию игрока

## Редкость карт

Карты имеют следующие уровни редкости:

- **Common (Обычная)** - базовые карты, легко доступные
- **Rare (Редкая)** - более сильные карты, встречаются реже
- **Epic (Эпическая)** - мощные карты с уникальными способностями
- **Legendary (Легендарная)** - самые редкие и сильные карты, включают знаменитых футболистов

## Система коллекции

### Управление картами

- **Добавление карт**: новые карты добавляются в коллекцию
- **Дубликаты**: если карта уже есть в коллекции, она считается дубликатом
- **Вознаграждение за дубликаты**:
  - Обычная карта: 5 единиц валюты
  - Редкая карта: 15 единиц валюты
  - Эпическая карта: 50 единиц валюты
  - Легендарная карта: 200 единиц валюты

### Улучшение карт

- Игроки могут использовать дубликаты карт для их улучшения
- Улучшенные карты получают бонусы к своим характеристикам
- Количество требуемых дубликатов зависит от редкости карты

## Прогресс и статистика

Система предоставляет игроку информацию о:

- Общем количестве карт в коллекции
- Заполнении коллекции в процентах
- Количестве карт по редкости
- Количестве карт по позициям (нападающие, полузащитники, защитники, вратари)
- Рекомендациях по дополнению коллекции (какие карты отсутствуют и наиболее ценные)

## Валюта игры

Игровая валюта используется для:

- Покупки пакетов карт
- Улучшения карт
- Обмена на специальные предметы

Игроки получают валюту:

- За открытие дубликатов карт
- За выполнение заданий и достижений
- За победы в матчах и турнирах
- В качестве наград

## Пример использования

```javascript
// Инициализация системы
const packSystem = new PackSystem();
const collectionSystem = new CollectionSystem();

// Инициализация коллекции игрока
collectionSystem.initializePlayerCollection('player123');

// Открытие пакета
const packResult = packSystem.openPack('premium', allCards);

// Добавление карт в коллекцию
const addResult = collectionSystem.addCardsToCollection('player123', packResult.cards);

// Получение статистики коллекции
const stats = collectionSystem.getCollectionCompletion('player123');
```
