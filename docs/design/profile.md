# Профиль — UX spec (CF-002a)

Догоняющая спецификация текущего экрана `mobile/CardFootball/screens/ProfileScreen.js`. Документ описывает поведение, которое уже в клиенте. Код mobile этой задачей не меняется.

Источник данных — `PackService` (локальная коллекция `test_player_123` в памяти процесса). Идентификатор игрока на экране не показывается. Перезапуск приложения сбрасывает коллекцию и монеты к стартовым. Отдельного аккаунта, аватара и никнейма нет: подзаголовок шапки — «Локальный профиль».

Нижняя вкладка навигатора: имя маршрута `Профиль`, иконка `person` / `person-outline`, активный тинт `#0066cc`. `headerShown: false` — системный header вкладки скрыт, шапка рисуется самим экраном. Нижний tab bar остаётся на loading, error и success.

## User flow

```
Нижнее меню «Профиль»
        │
        ▼
   Первый заход? ── да ──► loading (спиннер на весь экран под шапкой)
        │                         │
        нет                       ├─ сбой любого вызова PackService ──► error + «Повторить»
        │                         │
        ▼                         └─ все 6 вызовов success ──► success
 Тихий refresh (шапка,                           │
 вкладки и контент                               ├─ «Статистика» (по умолчанию)
 остаются, крутится                              ├─ «Коллекция»
 RefreshControl)                                 └─ «Активность»
        │
        └─ сбой ──► тот же error на весь экран (контент вкладок скрыт)
```

1. Игрок открывает вкладку «Профиль».
2. Экран на фокусе вызывает шесть методов `PackService` подряд: `getPlayerCollection`, `getCollectionCompletion`, `getCollectionStatsByRarity`, `getCollectionStatsByPosition`, `getPlayerCurrency`, `getCollectionRecommendations`. Любой `success: false` или исключение прерывает загрузку.
3. Первый успешный заход за сессию экрана показывает полноэкранный loading, затем success. Повторный фокус (возврат с «Пакеты», «Коллекция», «Команда») и pull-to-refresh обновляют данные тихо: полноэкранный loading не показывается, выбранная внутренняя вкладка не сбрасывается.
4. На success игрок переключает внутренние вкладки «Статистика» / «Коллекция» / «Активность». Переключение мгновенное, без анимации.
5. Пустая коллекция: на «Коллекции» кнопка «Открыть пакеты» делает `navigation.navigate('Пакеты')`.
6. Карточка в «Кого искать» открывает системный `Alert` и не меняет коллекцию.
7. «Повторить» на error снова запускает загрузку уже как первый показ (полноэкранный loading).

## Компоненты

Отдельных `CardItem` и `FormationSelector` на экране нет. Рекомендации — текстовые карточки, не полный арт карты.

| Компонент | Где | Роль |
|-----------|-----|------|
| Шапка | всегда | «Профиль», «Локальный профиль», чип монет только в success |
| `TabButton` × 3 | только success | Внутренние вкладки, `accessibilityRole="button"`, `accessibilityState.selected` |
| `StatsTab` | «Статистика» | Плитки аккаунта, прогресс коллекции, пустой блок матчей |
| `CollectionTab` | «Коллекция» | Прогресс, пустое состояние, сетки, рекомендации |
| `CountGrid` | «Коллекция», если собрано > 0 | «По редкости», «По позициям» |
| `RecommendationCard` | «Кого искать», если список не пуст | Имя, позиция, редкость, сила |
| `ActivityTab` | «Активность» | До трёх сводных событий или пустое состояние |
| `ActivityIndicator` | loading | Крупный спиннер `#0066cc` |
| `RefreshControl` | success, `ScrollView` | Pull-to-refresh, tint `#0066cc` |
| `Alert` | тап по рекомендации | Системный диалог, кнопка «OK» |

## Состояния

Процент заполнения на экране — `completionPercentage` из сервиса, зажатый в диапазон 0…100. Нечисловое значение показывается как 0. Округление до целого экран не делает: приходит `12.5` — подпись «12.5%».

Чип монет в шапке есть только при `status === 'ready'` и загруженном профиле. На loading и error шапка без чипа.

### Loading

- Шапка без чипа монет.
- По центру оставшейся высоты: спиннер и текст «Загрузка профиля...».
- Внутренних вкладок и `ScrollView` нет.
- Нижний tab bar доступен: уйти с экрана можно.

### Error

- Шапка без чипа.
- Иконка `alert-circle-outline`, 40, цвет `#c62828`.
- Заголовок «Не удалось загрузить профиль».
- Подзаголовок — `error` от упавшего вызова. Если сообщения нет: «Не удалось загрузить профиль».
- Запасные тексты, если сервис вернул `success: false` без `error`:
  - «Не удалось загрузить коллекцию»
  - «Не удалось посчитать заполнение коллекции»
  - «Не удалось посчитать карты по редкости»
  - «Не удалось посчитать карты по позициям»
  - «Не удалось загрузить монеты»
  - «Не удалось загрузить рекомендации»
- Кнопка «Повторить», высота ≥ 44 pt.
- Вкладок нет. Ранее загруженный профиль в этом состоянии не показывается, в том числе если сбой случился на тихом refresh или pull-to-refresh.

### Success

Шапка с чипом: число монет (`#FFD700`) и подпись «Монет». Число то же, что плитка «Монет» на «Статистике». Под шапкой сегмент из трёх вкладок. Контент скроллится; снизу запас 28 pt. Pull-to-refresh обновляет все шесть источников.

**Статистика**

Плитки в две колонки (~48% ширины):

| Подпись | Значение |
|---------|----------|
| Монет | `currency`, иначе 0 |
| В коллекции | `{collected}/{total}` |
| Получено карт | `cardsObtained`, иначе 0 |
| Дубликатов | `duplicateCards`, иначе 0 |
| Улучшений | `cardUpgrades`, иначе 0 |

Под плитками подпись «Коллекция заполнена на {percent}%» и полоса прогресса (трек `#eceff3`, заливка `#0066cc` на ширину процента).

Блок «Матчи» на success всегда пустой, даже если коллекция не пустая: иконка `football-outline`, «Матчей ещё не было», текст «Победы, ничьи и голы появятся здесь, когда история матчей будет сохраняться между экранами.»

**Коллекция**

- «Заполнение»: «{collected} из {total} карт · {percent}%» и та же полоса.
- Если `collected === 0`: пустой блок (см. Empty). Сеток редкости и позиций нет.
- Если `collected > 0`: «По редкости» и «По позициям».
- «Кого искать» показывается и при пустой коллекции. Подпись «Не хватает карт: {missingTotal}». В ленте не больше 10 карт. `missingTotal` может быть больше 10 — это размер всего недостающего каталога. Порядок ленты задаёт сервис: редкость legendary → epic → rare → common, внутри редкости сила по убыванию. Сила на карточке = `attack + defense + speed + technique` (отсутствующий стат считается 0).

Тап по карточке:

```
{name}
Позиция: {Нападающий|Полузащитник|Защитник|Вратарь|Позиция}
Редкость: {Обычные|Редкие|Эпические|Легендарные|{сырой ключ}}
Сила: {power}

Этой карты ещё нет в коллекции.
[OK]
```

Неизвестная позиция в подписи карточки и в алерте — «Позиция». Неизвестная редкость: рамка как у common (`#CCCCCC`), подпись редкости цветом `#666`, текст редкости — сырой ключ.

**Активность**

Сводка, не лента отдельных открытий. В список попадает событие только если счётчик > 0. Порядок фиксированный. У всех видимых строк одна и та же метка времени `collection.lastUpdated`. Пустая или неразбираемая метка не рисуется. Формат метки — `toLocaleString('ru-RU')`.

| Условие | id | Заголовок | Текст | Иконка |
|---------|-----|-----------|-------|--------|
| `cardsObtained > 0` | `cards-obtained` | Карты из пакетов | «Получено карт: N. Уникальных в коллекции: M» | `gift-outline` |
| `duplicateCards > 0` | `duplicates` | Дубликаты | «Дубликатов обменяно на монеты: N» | `albums-outline` |
| `cardUpgrades > 0` | `upgrades` | Улучшения | «Улучшений карт: N» | `trophy-outline` |

M — `collection.cards.length`, иначе 0.

### Empty

Пустые блоки живут внутри success. Отдельного статуса `empty` у экрана нет.

| Место | Когда | UI |
|-------|--------|-----|
| Коллекция → заполнение | `collected === 0` | «В коллекции пока нет карт». «Откройте пакет — новые карты появятся в профиле.» Кнопка «Открыть пакеты» → вкладка «Пакеты» |
| Коллекция → кого искать | `recommendations.length === 0` | «Рекомендаций нет». «Каталог собран — недостающих карт не осталось.» Горизонтальной ленты нет |
| Активность | ни один счётчик не > 0 | Иконка `time-outline`. «Пока нет событий». «Откройте пакет — здесь появится запись о полученных картах и дубликатах.» |
| Статистика → матчи | всегда на текущем экране | «Матчей ещё не было» (текст выше) |

Стартовый локальный профиль (паки в этой сессии не открывались): монеты 1000 (значение инициализации коллекции, экран его не хардкодит), собрано 0 из размера каталога, процент 0, активность пустая, «Кого искать» показывает до 10 карт и полный `missingTotal`.

## Art brief

Палитра совпадает с соседними вкладками (синий header, серый фон, белые карточки). Новый визуальный стиль и Lottie на профиль не входят в задачу (полный motion-pass — Icebox).

| Роль | Цвет |
|------|------|
| Фон экрана | `#f5f5f5` |
| Шапка, активная вкладка, заливка прогресса, кнопки, акцент иконок | `#0066cc` |
| Текст шапки | белый; подзаголовок и «Монет» — белый 85% |
| Чип монет | белая заливка 20%, скругление 20, число `#FFD700` |
| Карточка секции | белый, радиус 15, padding 16 |
| Плитка | `#f7f9fc`, радиус 12 |
| Основной текст | `#333` |
| Вторичный | `#666` |
| Описание активности | `#555` |
| Время | `#888` |
| Ошибка | `#c62828` |
| Трек прогресса | `#eceff3` |
| Подложка иконки активности | `#e8f1fb`, круг 44 |

Иерархия сверху вниз: шапка (название + монеты) → сегмент вкладок → заголовок секции 16 bold → крупное число плитки 18 bold → подпись 12 → пояснение 14. На рекомендации имя 15 bold важнее позиции и редкости; сила — нижняя строка.

Редкость (рамка рекомендации 2 pt и точка 10 pt в сетке):

| Ключ | Подпись в сетке | Подпись на карточке рекомендации | Цвет |
|------|-----------------|----------------------------------|------|
| `common` | Обычные | Обычные | `#CCCCCC`, текст редкости на карточке `#666` (светлый бордюр на белом не используется как цвет текста) |
| `rare` | Редкие | Редкие | `#1E90FF` |
| `epic` | Эпические | Эпические | `#8A2BE2` |
| `legendary` | Легендарные | Легендарные | `#FFD700` |

Позиции в сетке: Нападающие, Полузащитники, Защитники, Вратари. На карточке и в алерте — единственное число: Нападающий, Полузащитник, Защитник, Вратарь.

Движение: спиннер загрузки и системный refresh. Смена внутренней вкладки без перехода. Диалог рекомендации — нативный Alert. Портретов игроков нет.

Касания: вкладки, чип монет, «Повторить», «Открыть пакеты», строка активности — не ниже 44 pt по высоте. Карточка рекомендации 148 × не ниже 120 pt. Плитки статистики не кнопки (высота не ниже 64 pt).

Ширина: один и тот же макет на телефоне и планшете. Плитки остаются в две колонки (`48%`), лента рекомендаций скроллится горизонтально, вкладки делят ширину поровну (подпись 13 pt). Отдельной планшетной сетки нет. Верхний отступ шапки фиксированный 48 pt, без safe area insets.

## AC для QA

Проверять на вкладке «Профиль» текущего клиента. Автотестов экрана нет: чеклист ручной. Ожидание ниже — норма текущей сборки, пока spec и экран совпадают.

| # | Сценарий | Ожидание | Статус |
|---|----------|----------|--------|
| 1 | Given свежий запуск, паки не открывались. When открыть «Профиль». | Сначала «Загрузка профиля...» без чипа монет и без внутренних вкладок. Затем success: «Профиль» / «Локальный профиль», чип 1000 «Монет», открыта «Статистика». Плитки: 1000, 0/{размер каталога}, 0, 0, 0. Прогресс 0%. Блок матчей — «Матчей ещё не было». | |
| 2 | When на этом профиле открыть «Коллекция». | «0 из N карт · 0%». «В коллекции пока нет карт» и «Открыть пакеты». Сеток «По редкости» и «По позициям» нет. «Кого искать»: «Не хватает карт: N», лента до 10 карточек. | |
| 3 | When нажать «Открыть пакеты». | Активна нижняя вкладка «Пакеты». | |
| 4 | Given в ленте есть карта. When нажать карточку. | Alert: имя, русская позиция, русская редкость, сила = сумма четырёх статов, фраза «Этой карты ещё нет в коллекции.», кнопка OK. После OK коллекция и монеты те же. Рамка: common `#CCCCCC`, rare `#1E90FF`, epic `#8A2BE2`, legendary `#FFD700`. Текст редкости common — `#666`, у остальных совпадает с рамкой. | |
| 5 | Given открыт пак и получена хотя бы одна новая карта. When вернуться на «Профиль». | Полноэкранного «Загрузка профиля...» нет. Чип и «В коллекции» выросли, прогресс > 0. На «Коллекции» видны обе сетки, счётчики сходятся с собранными картами (нет карты — 0). | |
| 6 | Given `cardsObtained > 0`. When открыть «Активность». | Строка «Карты из пакетов», иконка gift, текст с числом полученных и уникальных, время в русской локали. | |
| 7 | Given только `duplicateCards > 0`, остальные два счётчика 0. When «Активность». | Одна строка «Дубликаты», иконка albums. Строк про пакеты и улучшения нет. | |
| 8 | Given все три счётчика 0. When «Активность». | «Пока нет событий» и иконка time. | |
| 9 | Given каталог собран целиком. When «Коллекция». | «Не хватает карт: 0», «Рекомендаций нет», «Каталог собран — недостающих карт не осталось.». Ленты нет. Прогресс 100% (или значение сервиса, зажатое в 100). | |
| 10 | Given любой из шести методов `PackService` вернул `success: false` при первом заходе. When открыть «Профиль». | Шапка на месте, чипа нет. Заголовок ошибки, текст из `error` или запасной текст этого метода, «Повторить». Вкладок нет. | |
| 11 | When на error нажать «Повторить» и сервисы отвечают success. | Снова полноэкранный loading, затем success. | |
| 12 | Given success и выбрана не «Статистика». When pull-to-refresh. | Индикатор обновления, без полноэкранного loading. Та же внутренняя вкладка. Числа совпадают с сервисом. | |
| 13 | Given экран уже в success. When тихий refresh или pull падает. | Весь контент сменяется error. «Повторить» снова показывает полноэкранный loading. | |
| 14 | Given коллекция не пустая. When «Статистика». | Блок «Матчи» по-прежнему «Матчей ещё не было». | |
| 15 | When переключать три внутренние вкладки. | Активная: фон `#0066cc`, текст белый, selected. Неактивная: текст `#333`. Высота кнопки ≥ 44 pt. Чип монет, «Повторить», «Открыть пакеты», строка активности — высота ≥ 44 pt. | |
| 16 | Given `completionPercentage` не число, < 0 или > 100. | Подпись и ширина полосы используют 0 или 100, не отрицательную и не больше 100. | |

Расхождение экрана с этой таблицей — дефект для @agent-frontend-rn. Менять `ProfileScreen.js` в CF-002a не нужно.

## Вне скоупа

- История матчей, победы, ничьи, голы.
- Аватар, ник, авторизация, серверный профиль.
- Сохранение коллекции между запусками.
- Правки `game_logic/` и баланс.
- Lottie и новый визуальный стиль.
- Вынос строк в `docs/content/copy-ru.md` (CF-108).
