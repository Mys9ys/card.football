# 01 — Прожектор

Ночной кубок: коллекция как табло под прожекторами, а не форма на белом фоне. Зайдёт тем, кто хочет чувствовать матч в момент, когда карта редкости загорается рамкой.

Механики, редкости `common → legendary`, статы (атака, защита, скорость, техника) и схемы состава не меняются. Портрет до пайплайна арта — тёмный силуэт с контровым светом, не серый прямоугольник «Изображение».

## Design tokens

Сетка 8 pt. Цвет редкости — рамка, свечение и плашка бейджа. Мелкий текст на фольге не пишется: чернила бейджа отдельно от хрома.

## Карточка коллекции

Пропорция **2:3**. В сетке на 360 px карточка около 156 pt: команда есть, страна уходит в подробный лист по тапу. Имя — до 2 строк. Амплуа коротко: ВР, ЗЩ, ПЗ, АТ.

```
┌─────────────────┐
│ 82          РЕДК│  ОВР + бейдж редкости
│                 │
│   силуэт,       │  контровый свет secondary
│   обод #8EBEFF  │
│                 │
│ Алексей Смирнов │
│ АТ · Спартак    │
│ АТК 88   ЗАЩ 70 │  полоска залита до значения
│ СКР 85   ТЕХ 83 │
└─────────────────┘
```

- Лицо: ОВР (среднее четырёх статов, как в текущем `CardItem`), бейдж редкости, силуэт, имя, амплуа, клуб, четыре полоски. Способности на лице не выводятся — только в листе по тапу.
- Press: scale `0.97` за 120 ms, рамка ярче. Отпускание возвращает spring.
- Легендарная: по рамке раз в 4 с проходит диагональный блик 8% белого, 700 ms. Свечение золотое, не красное (красный занят кнопками). `reduce motion`: блик выключен, рамка и плашка статичны.
- Пустая коллекция использует ту же пропорцию как пунктирный слот `#2A3344`, без портрета и без бейджа редкости.
- Полная коллекция: те же рамки, легендарные читаются светящейся кромкой среди обычных.

## Экраны

### Коллекция

Шапка на `surface`: «Коллекция» и счётчик «N из M». Чипы редкости высотой 44 pt, полные слова «Все / Обычные / Редкие / Эпические / Легендарные», горизонтальный скролл — на 360 px ряд не сжимает шрифт и не ставит многоточие.

Сетка: 2 колонки, gap 8, поля 16. Планшет от 600 pt — 4 колонки, та же 2:3.

- Loading: два ряда силуэтов карт `surface` ярче фона, без синего спиннера на белом.
- Empty: три пунктирных слота и кнопка «Открыть пакет» на всю ширину, ≥ 44 pt.
- Error: текст ошибки `text` и «Повторить» primary.
- Success, полный альбом: скролл, фильтр не прячет рамку редкости.

### Открытие пака

Пачка покрашена по своему типу из коллекции (стартовый — сталь common, легендарный пак — золотая кромка), дроп-рейты не меняются.

1. Свет гаснет до `#070B14`.
2. Кнопка «Открыть» ≥ 44 pt.
3. Один прожектор снизу поднимает **лучшую** карту пака. Остальные четыре остаются тёмными полосками.
4. Карта садится в центр, рамка редкости загорается. Если это дубликат — подпись «Дубликат · монеты +N». В сетку вторая копия не кладётся (дубликат по-прежнему обмен на валюту).
5. Затем веер из пяти лиц. Тап по рубашке переворачивает одну карту.

`reduce motion`: без подъёма, карты сразу лицом, свечение статично.

### Команда

Поле — полосатый прямоугольник со скруглением 12, центр и штрафная линиями. Это замена битой картинки поля: растр не используется.

Слот ≥ 44 pt (визуал можно 48). Пустой: пунктир `#9CC8FF`, буква амплуа. Занятый: мини-лицо 2:3 с рамкой редкости и ОВР. Кнопка схемы («4-4-2» и остальные из концепции) — чип secondary. «Сохранить состав» — primary на всю ширину, текст целиком, при нехватке ширины две строки, не ellipsis. Неполный состав — приглушённая кнопка `#3A4254`, текст `#C3CEDF`.

## Navigation

Tab bar `surface`, высота 56 + safe area. Иконка 24. Подписи 12 pt целиком: Пакеты, Коллекция, Команда, Профиль. Активная — `#FF4B3E` иконка и текст, неактивная `#8E98AD`.

Шапка не отдельная синяя плашка: тот же `#161E30`, заголовок Russo One `#F5F7FB`, нижняя кромка 1 pt `#2A354C`.

## Плюсы / минусы / риски

- Плюс: редкость видна в сетке из двух колонок без чтения бейджа — свечение против тёмного газона.
- Минус: тёмный UI просит отдельные пары для ошибок и пустых слотов, иначе экран «пропадает».
- Риск: золото легендарной и красный CTA спорят, если кнопку тоже сделать золотой. Золото только у редкости.

## AC для Frontend

После выбора этого направления:

1. Экраны Коллекция, Пакеты, Команда, Профиль на `#0B1020` / `#161E30`. Кнопки `#FF4B3E`. Цвета `#0066cc` в этих экранах нет.
2. Карта 2:3. Рамки, glow и текст бейджей совпадают с таблицей. «ЛЕГЕН» — `#2A2108` на `#F0CC6A`. У common нет glow. При `reduce motion` блик легендарной не играет.
3. На ширине 360 — 2 колонки, имя до 2 строк, чипы редкости полными словами и высотой ≥ 44. Пустая коллекция: пунктирные слоты и «Открыть пакет». Полная: скролл, легендарная отличается свечением.
4. Reveal: лучшая карта пака под прожектором, затем пять лиц. Дубликат показывает обмен на монеты и не дублирует карту в сетке.
5. Поле — полосы `#1F6B45` / `#184E34` без `Image`. Слот ≥ 44 pt. «Сохранить состав» не обрезается на 360 px.
