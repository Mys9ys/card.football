# Выбранный дизайн: Шарик (Bubble)

**Решение заказчика:** 27 Oct 2026.  
**Источник превью:** `docs/design/directions/preview/` (направление `bubble`).  
**Дальше:** развиваем UI mobile вокруг этих токенов (CF-110 / скинирование экранов).

## Почему

Мягкая мультяшность: толстые скругления, pill-ярлыки редкости, круг OVR, конфетные цвета. Карты, команда и общий mood совпали с ожиданиями.

## Карта

- Пропорция портрета высокая; `object-position` ближе к верху, чтобы голова не обрезалась.
- OVR — белый круг с цветной кромкой редкости, слегка наезжает на низ портрета.
- Редкость — pill-ярлык справа сверху (ОБЫЧН / РЕДК / ЭПИК / ЛЕГЕН).
- Имя сразу под портретом; длинное имя — меньший кегль, одна строка.
- На лице карты **только амплуа** (АТ / ПЗ / ЗЩ / ВР). Клуб (Спартак и т.п.) на карте не пишем — для MVP не нужен; поле `team` в данных может остаться.
- Высота карты фиксирована без пустого «хвоста» под статами.
