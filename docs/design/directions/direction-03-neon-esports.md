# 03 — Неоновый дерби

Эфир киберспортивного дерби: интерфейс почти чёрный и тихий, а неон принадлежит только картам. Зайдёт тем, кто узнаёт редкость по ореолу, как подсветку скина.

Правила матча и паков те же. Портрет до арта — контурный бюст с кромкой цвета редкости на `#12141C`.

## Карточка коллекции

Пропорция **2:3**. Углы срезаны слегка (радиус 6), верхний правый угол — фаска 10 pt, как бейдж HUD.

```
┌─────────────────┐
│ 82              │
│             РЕДК│  бейдж в фаске
│                 │
│   контур бюста  │  обводка цветом рамки
│                 │
│ СМИРНОВ         │  Unbounded, верхний регистр если влезает
│ АТ · СПАРТАК    │
│ АТК ████░░  88  │
│ ЗАЩ ███░░░  70  │
│ СКР ████░░  85  │
│ ТЕХ ████░░  83  │
└─────────────────┘
```

Длинное имя на 2 строки в обычном регистре, если верхний не помещается на 156 pt. «Алексей Смирнов» остаётся читаемым: регистр не обязателен.

- Лицо: ОВР, бейдж, контур, имя, амплуа, клуб, четыре полоски. Страна и способности — в листе.
- Press: scale `0.97`, glow на 15% ярче на время нажатия.
- Легендарная: непрозрачность ореола пульсирует 0.45–0.85 за 1.6 с. Двойная кромка золото + циан держится. `reduce motion`: ореол статичен на 0.6.
- Пустая сетка: слот с кромкой `#3A4154` без ореола.
- Полная сетка: обычные гаснут, редкие и выше светятся. Легендарная — единственная с двойной кромкой.

## Экраны

### Коллекция

Фон `#090A10`. Заголовок «Коллекция», счётчик «N из M» цветом `#B8C0D8`. Чипы 44 pt, обводка `#3A4154`, активный чип — заливка `#F4F6FB` и текст `#12131A`. Слова целиком, горизонтальный скролл на 360 px.

2 колонки на телефоне, 4 от 600 pt.

- Loading: тёмные плитки 2:3, кромка `#232838`.
- Empty: «Карт пока нет» и «Открыть пакет» (белая кнопка, тёмный текст) ≥ 44 pt.
- Error: рамка слота `#FF4AD8` только у сообщения, кнопка «Повторить» белая. Текст ошибки `#F4F6FB`.
- Success: скролл. Ореолы не перекрывают соседнее имя: glow наружу, внутренние поля карты 8 pt.

### Открытие пака

Корпус пака — тёмная капсула. Кромка капсулы = лучшая редкость типа пака. Шансы дропа не рисуются неоном заново и не меняются.

1. Капсула по центру на `#090A10`.
2. «Открыть».
3. Корпус расходится по горизонтали. Лучшая карта переворачивается по оси Y.
4. Ореол вспыхивает и садится в значение из таблицы. Дубликат: строка «Дубликат · монеты +N» под картой, цвет `#B8C0D8`.
5. Четыре остальные выезжают в ряд под героем.

`reduce motion`: сразу пять лиц, без поворота.

### Команда

Поле — неоновый контур газона, не картинка. Пустой слот: ромб 48 pt, кромка `#3A4154`, буква амплуа `#F4F6FB`. Занятый: мини-карта 2:3 с ореолом редкости. Слот ловит нажатие ≥ 44 pt.

«Сохранить состав» — белая кнопка на всю ширину, текст целиком. Неполный состав: обводка без заливки, текст `#9AA3B8`.

## Navigation

Tab bar `#141722`, верх 1 pt `#262A38`. Высота 56 + safe area. Активная вкладка: текст `#F4F6FB` и индикатор-чёрточка 16×2 `#39E1FF` над иконкой. Неактивная `#8B93A7`. Подписи 12 pt: Пакеты, Коллекция, Команда, Профиль — без обрезки. Циан индикатора не путать с заливкой кнопки.

Шапка `#090A10`, заголовок Unbounded, без отдельной цветной полосы.

## Плюсы / минусы / риски

- Плюс: в полной сетке редкость сортируется глазом по силе ореола. Reveal читается без текста.
- Минус: много свечения сажает контраст и батарею, если подсветить ещё и tab bar.
- Риск: циан и маджента на `#090A10` не проходят AA мелким кеглем. Спека оставляет их на рамках. Текст бейджа — светлый на тёмной плашке или тёмный на золоте.

## AC для Frontend

После выбора этого направления:

1. Фон `#090A10`, кнопки `#F4F6FB` с текстом `#12131A`. `#0066cc` нет. Tab bar не залит неоном.
2. Карта 2:3. Common без glow. Rare — циан, epic — маджента, legendary — двойная кромка `#FFE08A` + `#39E1FF`. «ЛЕГЕН» — `#1A1408` на `#FFE08A`. Пульс выключен при `reduce motion`.
3. 2 колонки на 360 px, чипы ≥ 44 pt полными словами. Пустая коллекция без ореолов. Полная — ореол не перекрывает имя соседней карты.
4. Reveal: капсула расходится, герой переворачивается, дубликат подписан монетами и не копируется в сетку.
5. Поле — контур без `Image`. Слот ≥ 44 pt. «Сохранить состав» не обрезается на 360 px.
