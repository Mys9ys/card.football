# 04 — Витрина

Тихая полка: много воздуха, тонкая металлическая кромка, ни одного ореола. Зайдёт тем, кто хочет рассматривать карту, а не интерфейс вокруг неё.

Тот же набор данных игрока. Портрет до арта — один контур чернилами `#1A1916` на `#F6F4F0`, без серой плашки.

## Карточка коллекции

Пропорция **3:4** — чуть ниже, чем у соседних направлений, чтобы на полке оставался воздух над именем. Сетка всё равно 2 колонки.

```
┌───────────────┐
│ 82            │  ОВР крупно, без плашки
│ РЕДК          │  слово + штрих цвета редкости
│               │
│   контур      │  много поля вокруг силуэта
│               │
│ Алексей       │
│ Смирнов       │
│ АТ            │
│ Спартак       │
│ 88  70  85  83│  цифры одной строкой
│ АТК ЗАЩ СКР ТЕХ
└───────────────┘
```

- Лицо: кромка 1 pt, ОВР, короткое слово редкости со штрихом, контур, имя на две строки, амплуа, клуб, четыре числа. Страна и способности — ниже на листе по тапу, тем же кеглем body.
- Press: opacity `0.92` на 80 ms, без scale и без вспышки. Рамка легендарной на press светлеет до `#C4A15A` и возвращается.
- Легендарная в покое не анимируется. Нет блика, нет пульса. Отличие от epic — толщина 1.5 pt и цвет золота на штрихе.
- Пустая полка: одна горизонтальная линия и текст, без десятков пустых рамок.
- Полная полка: ритм одинаковых рамок. Редкость читается штрихом и цветом кромки, не заливкой фона. Фон всех карт `#F6F4F0`.

## Экраны

### Коллекция

Фон `#E8E4DC`. «Коллекция» и «N из M» одной колонкой, без цветной шапки. Чипы — текст 14 pt в рамке 1 pt, высота 44, активный чип залит `#1A1916` с текстом `#F6F4F0`. Полные слова, скролл на 360 px.

2 колонки на телефоне, 4 от 600 pt, gap 12.

- Loading: три линии-скелета на `surface`, без спиннера брендового цвета.
- Empty: «На полке пусто.» Вторая строка «Откройте пакет, чтобы поставить первую карту.» Кнопка «Открыть пакет» ≥ 44 pt.
- Error: «Не удалось открыть полку» и «Повторить». Цвет текста `#1A1916`, кнопка primary.
- Success: карты не слипаются. У легендарной кромка заметно теплее графитовой common на одном экране.

### Открытие пака

Коробка без иллюстрации взрыва. Клапан цвета редкости типа пака — тонкая полоска 4 pt на крышке `#F6F4F0`.

1. Крышка на фоне полки.
2. «Открыть».
3. Крышка уезжает вверх на 240 ms. Пять карт лежат в ряд лицом вниз (руб цвета `#E8E4DC`, кромка `#D9D3C8`).
4. Лучшая переворачивается первой. Имя появляется через 200 ms после лица. Дубликат: строка «Дубликат · +N монет» цветом `#5E5A54`, без штампа и без тряски.
5. Остальные открываются слева направо по тапу или кнопкой «Открыть все».

`reduce motion`: крышка уже открыта, карты лицом, имена сразу.

### Команда

Поле — светлый чертёж на всю ширину контента. Пустой слот: квадрат 48 pt, линия `#B7B1A6`, буква амплуа `#1A1916`. Занятый: мини-карта 3:4 с той же кромкой редкости. Касание ≥ 44 pt.

Схема («4-4-2») — текстовая кнопка-чип. «Сохранить состав» — чёрная, на всю ширину, две строки допустимы, обрезки нет. Неполный состав: рамка `#B7B1A6`, текст `#5E5A54`, без заливки.

## Navigation

Tab bar `#E8E4DC`, верхняя линия `#D9D3C8`. Высота 56 + safe area. Активная — `#1A1916`, неактивная `#8C867C`. Подписи 12 pt целиком.

Шапка совпадает с фоном. Заголовок Manrope 600. Отдельной цветной полосы нет.

## Плюсы / минусы / риски

- Плюс: контраст текста проще удержать. AA держится на чернилах, цвет редкости не несёт мелких подписей.
- Минус: reveal тихий. Первая легендарная должна отличаться кромкой сразу, потому что вспышки нет.
- Риск: если сжать поля ради «больше карт», полка станет очередной плотной сеткой. Поле 20 pt на телефоне сохраняется.

## AC для Frontend

После выбора этого направления:

1. Фон `#E8E4DC`, карта `#F6F4F0`, кнопки `#1A1916` с текстом `#F6F4F0`. `#0066cc` нет. Теней у карт нет.
2. Пропорция 3:4, радиус 2. Кромки по таблице, glow нет ни у одной редкости. «ЛЕГЕН» — `#1A1916`, штрих `#8C7040`. Фон карты не красится под редкость.
3. 2 колонки на 360 px при полях 20 pt. Пустая полка — текст и «Открыть пакет» ≥ 44 pt, без пачки пустых рамок. Полная полка: common и legendary различимы кромкой на одном экране.
4. Reveal: крышка уезжает, лучшая карта открывается первой, дубликат подписан монетами без второй копии в коллекции. При `reduce motion` имена видны сразу.
5. Поле — заливка `#D7E0D6` и линии без `Image`. Слот ≥ 44 pt. «Сохранить состав» не обрезается на 360 px.
