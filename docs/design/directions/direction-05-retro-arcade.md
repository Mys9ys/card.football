# 05 — Автомат '98

Кабинет автомата: фанерная рамка, люминофор экрана, карта как спрайт. Зайдёт тем, кто хочет характер и короткий reveal без фотореализма.

Кириллица не сажается на Press Start 2P и Orbitron — у них нет русской буквы. Заголовки: Russo One. Цифры ОВР можно моноширинным системным. Пиксельный вид делают радиус 0, палитра из восьми цветов и жёсткая тень, а не латинский bitmap-шрифт.

Механики те же. Портрет до арта — бюст 32×32, растянутый без сглаживания (`imageRendering` nearest / RN без интерполяции), 4 цвета люминофора.

## Карточка коллекции

Пропорция **2:3**, углы прямые. В сетке карта стоит на чёрной «подставке» 4 px, если она легендарная. Остальные лежат плоско на стекле.

```
┌─────────────────┐
│82           РЕДК│
│ ┌────┐          │
│ │::::│  АТ      │  пиксельный бюст слева
│ └────┘          │
│ А. СМИРНОВ      │  имя до 2 строк, Russo One
│ СПАРТАК         │
│ АТК 88          │
│ ЗАЩ 70          │
│ СКР 85          │
│ ТЕХ 83          │
└─────────────────┘
```

- Лицо: ОВР, бейдж, спрайт, амплуа, имя, клуб, четыре строки статов. Страна и способности — на листе по тапу, тем же люминофором.
- Press: сдвиг карты на `2 px` вниз-вправо на 80 ms, как нажатая кнопка автомата. Scale нет.
- Легендарная: звезда 6×6 в верхнем левом углу меняет кадр каждые 400 ms (2 кадра). Тень `4 4 0` всегда. `reduce motion`: кадр 1, без мигания.
- Пустая коллекция: на стекле один спрайт пустого слота (пунктир 2 px `#8B9078`) и кнопка. Не поле из сотни пустых клеток.
- Полная: обычные без тени, легендарные приподняты чёрным сдвигом — видны при быстром скролле.

## Экраны

### Коллекция

Кабинет `#2A1240` по краям, рабочее стекло с полями 8. Заголовок «Коллекция» Russo One `#F2D15C`, счётчик «N из M» `#E7FFC4`. Чипы высотой 44, радиус 0, полные слова, горизонтальный скролл на 360 px. Активный чип — заливка `#F2D15C`, текст `#24180A`.

2 колонки на телефоне, 4 от 600 pt, gap 8.

- Loading: мигающий курсор-блок 8×16 `#E7FFC4` и три пустые рамки. Один цикл 600 ms; при `reduce motion` курсор статичен.
- Empty: «Карт нет» и кнопка «Открыть пакет» ≥ 44 pt.
- Error: текст `#FF5A6A`, кнопка «Повторить» жетоном `#F2D15C`.
- Success: скролл стекла. Имя не вылезает за рамку: 2 строки и хвост обрезки только у имени, не у кнопки.

### Открытие пака

Пак — пиксельный конверт на стекле. Полоска на конверте цветом лучшей редкости типа, дроп не меняется.

1. Три узких «барабана» (пустые рамки) над конвертом.
2. «Открыть».
3. Барабаны останавливаются по очереди за 400 ms. На последнем — герб редкости лучшей карты.
4. Карта падает сверху на 2 px ниже финальной точки и возвращается за 80 ms (удар). Легендарная дополнительно включает мигающую звезду.
5. Подпись дубликата: «ДУБЛИКАТ +N» цветом `#F2D15C` на стекле. Вторая копия в сетку не добавляется.
6. Ряд из пяти спрайтов.

`reduce motion`: барабаны уже остановлены, карта без удара, звезда на кадре 1.

### Команда

Поле из клеток внутри стекла. Пустой слот — квадрат 48 pt, пунктир `#E7FFC4`, буква амплуа. Занятый — мини-спрайт и ОВР под ним, рамка цветом редкости. Касание ≥ 44 pt.

«Сохранить состав» — жетон на всю ширину, тень `3 3 0 #000`, текст `#24180A` целиком, две строки допустимы. Неполный состав: рамка `#8B9078` без заливки, текст `#9BB892`.

## Navigation

Tab bar на цвете кабинета `#2A1240`, высота 56 + safe area. Активная подпись `#F2D15C`, неактивная `#9BB892`. Подписи 12 pt без обрезки. Иконки можно оставить Ionicons, цвет по состоянию, без неона.

Шапка — верх стекла `#141A12`, заголовок `#F2D15C`. Кабинет виден только по бокам на широком экране и в tab bar. На 360 px боковые поля кабинета 0, чтобы не съедать сетку: кабинет = tab bar и внешний фон под стеклом.

## Плюсы / минусы / риски

- Плюс: дешёвый motion (сдвиг на 2 px, 2 кадра звезды) уже даёт автомат. Сетка читается в два цвета: плоско / с чёрной тенью.
- Минус: пиксельный портрет условный, пока нет спрайтов. Силуэт 32×32 обязателен, иначе карта снова пустой прямоугольник.
- Риск: латинский pixel-font ломает «Сохранить состав» и имена. Спека запрещает его для любых русских строк.

## AC для Frontend

После выбора этого направления:

1. Стекло `#141A12`, кабинет tab bar `#2A1240`, кнопки `#F2D15C` с текстом `#24180A`. Радиус карт и кнопок 0. `#0066cc` нет.
2. Карта 2:3. Рамки по таблице. У legendary тень `4 4 0 #000` и бейдж `#24180A` на `#F2D15C`. Русские строки не набраны Press Start 2P. `reduce motion` держит звезду на одном кадре.
3. 2 колонки на 360 px, чипы ≥ 44 pt словами целиком. Пустое состояние — один пунктирный слот и «Открыть пакет». Полное — легендарные отделены жёсткой тенью.
4. Reveal: три барабана, удар карты на 2 px, дубликат строкой «ДУБЛИКАТ +N» без второй копии в коллекции.
5. Поле из клеток `#1E4A28` / `#173C20` без `Image`. Слот ≥ 44 pt. «Сохранить состав» не обрезается на 360 px.
