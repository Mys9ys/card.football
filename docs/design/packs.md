# Пакеты — UX Bubble (CF-110b design)

Перерисовка экрана «Пакеты» и блока статистики коллекции под выбранный стиль **Шарик**.  
Канон токенов: `docs/design/directions/chosen-bubble.md`.  
Код: `PackOpeningScreen.js`, `PackCard.js`, `CollectionStats.js`.  
Ассет упаковки: `assets/theme/pack-bubble.jpg` (**мячи**, не звёзды).

Ширина ориентира: **390px** (телефон). Touch targets ≥ **44pt**.

---

## 1. Layout экрана

Вертикальный скролл. Один столбец. Сверху вниз:

```
┌─────────────────────────────┐  bar #9BE7FF
│  Пакеты          🪙 1000    │  баланс всегда в шапке (чип coinBg)
├─────────────────────────────┤
│         [ hero пака ]       │  pack-bubble.jpg, ~168×220, radius 24
│     «Открой новый пак»      │  одна короткая строка muted
├─────────────────────────────┤
│  CollectionStats (компакт)  │  surface #FFF7FB, без пустых полос
├─────────────────────────────┤
│  Доступные пакеты           │
│  ┌─ PackCard ─────────────┐ │
│  └────────────────────────┘ │
│  ┌─ PackCard ─────────────┐ │
│  …                          │
└─────────────────────────────┘  bg #DFF6FF
```

### Правила

| Блок | Поведение |
|------|-----------|
| Шапка | Не дублировать системный header вкладки, если он уже «Пакеты». Либо `headerShown: false` + своя шапка (как Профиль), либо оставить nav header и рисовать только баланс + hero. **Рекомендация:** своя шапка Bubble, `headerShown: false` на вкладке «Пакеты». |
| Баланс | Только в шапке (pill `#FF6B8A`, текст белый). **Не** дублировать жёлтой строкой внизу статистики. |
| Hero | Один визуальный якорь — упаковка с мячами. Не список иллюстраций. |
| Статистика | Компактная карточка под hero, высота без «воздуха»: прогресс + ряд чипов редкости. |
| Список паков | Вертикальный. На 390px — одна колонка. Gap 12. Поля экрана 16. |
| Длинный список | Сейчас 6 типов — ок. Если станет > 8: горизонтальные чипы фильтра по тиру (Стандарт / Премиум / Легенда), без смены механик. |

### User flow

```
Таб «Пакеты»
  → loading (скелет / спиннер)
  → ready: hero + stats + PackCard list
      → тап PackCard
          → currency < price → insufficient coins
          → confirm → opening (блок UI)
          → success reveal
          → закрыть → список, баланс и чипы обновлены
      → сбой сервиса → error + «Повторить»
```

## 2. Карточка пака (`PackCard`)

Не текстовый бланк. Ощущение коллекционной упаковки: рамка по тиру, мини-арт мячей, явный CTA.

### Маппинг типа пака → визуальный тир (рамка / бейдж)

Тир задаёт **максимальную** гарантированную или характерную редкость пака (не ломает drop rates из `CARD_COLLECTION_SYSTEM.md`):

| pack.id | Тир UI | border | badge bg / text | Подпись бейджа |
|---------|--------|--------|-----------------|----------------|
| `starter` | common | `#A8B0D0` | `#EEF1FF` / `#5A6288` | ОБЫЧН |
| `standard` | rare | `#5AD0FF` | `#D9F5FF` / `#0A6F96` | РЕДК |
| `premium`, `defense_pack` | epic | `#C77DFF` | `#F3E4FF` / `#6B2EA8` | ЭПИК |
| `legendary`, `golden_legends` | legendary | `#FFD166` | `#FFE8A3` / `#8A5A00` | ЛЕГЕН |

Legacy `#0066cc` / `#1E90FF` / `#32CD32` на рамках **запрещены**.

### Структура PackCard (390px, поля 16 → ширина контента ~358)

```
┌──────────────────────────────────────┐  border 3, radius 22, bg #FFF7FB
│ [РЕДК]              100 🪙           │  pill-бейдж + цена text #2A2150
│                                      │
│   ○○  мини-ряд из 3 мячей-иконок     │  не звёзды; tint под тир
│                                      │
│ Стандартный пакет                    │  title 17 bold
│ 5 карт · легенда 2%                  │  одна строка meta muted
│ Гарантия: —                          │  или короткая строка, если есть
│                                      │
│        [ Открыть ]                   │  CTA primary, ≥ 44pt высота
└──────────────────────────────────────┘
```

### Детали

- **Цена:** число + «монет» или иконка монеты. Цвет `#2A2150`, не золотой `#FFD700` на белом (плохой контраст и не Bubble).
- **CTA:** фон `#FF6B8A`, текст `#FFFFFF`, radius 999, minHeight 44, на всю ширину контента минус padding. Подпись «Открыть» (не «КУПИТЬ» капсом legacy).
- **Press:** scale `0.98`, 120 ms.
- **Disabled / opening:** CTA opacity 0.45, `pointerEvents` none на карточке.
- **Гарантия:** если `guaranteedLegendary|Epic|Rare` — одна строка «Гарантия: легенда / эпик / редкая» цветом тира. Без зелёных галочек `#006400`.
- **Описание:** полное `description` из данных — только в expand/Alert по long-press или вторичной ссылке «Подробнее». На карточке в списке — максимум одна строка meta (карты + шанс легенды).
- **Арт:** маленькие мячи (Vector/emoji ⚽ или SVG). Hero сверху экрана уже несёт `pack-bubble.jpg`; на каждой PackCard — декоративный ряд, не вторая огромная картинка.

## 3. Статистика коллекции (`CollectionStats`)

Убрать: заголовок-простыню, пустой блок «по редкости» без чисел, жёлтый «Баланс: …» (баланс уже в шапке).

### Компактный блок

```
┌────────────────────────────────────┐  #FFF7FB, radius 22, padding 12–14
│  Альбом  0 / 20          0%        │  text + muted
│  ████░░░░░░░░░░░░░░░░              │  track #E5F7FF, fill #5AD0FF
│                                    │
│  [ОБЫЧН 0] [РЕДК 0] [ЭПИК 0] [ЛЕГЕН 0] │  ряд pill-чипов
│                                    │
│  АТ 0   ПЗ 0   ЗЩ 0   ВР 0         │  опционально, если statsByPosition есть
└────────────────────────────────────┘
```

### Чипы редкости

| Ключ | Подпись | Стили |
|------|---------|--------|
| common | ОБЫЧН | border/badge common |
| rare | РЕДК | rare |
| epic | ЭПИК | epic |
| legendary | ЛЕГЕН | legendary |

- Каждый чип: minHeight **44**, paddingHorizontal 10, radius 999, число bold справа или под подписью.
- Длинные слова «Обычные / Легендарные» **не** использовать в этом блоке.
- Если `stats` пустой объект — показывать четыре чипа с `0`, не прятать ряд.

### Амплуа (вместо длинных «Нападающие…»)

Если `statsByPosition` доступен с экрана — второй ряд мини-блоков: **АТ / ПЗ / ЗЩ / ВР** + число. Без иконок Ionicons обязательно; достаточно букв в круге 36–40 pt. Если данных нет — ряд амплуа не рисовать (не показывать заглушку «нет данных»).

### Прогресс

- Fill всегда `#5AD0FF` (не красный/зелёный traffic-light).
- Высота трека 10–12. Подпись «N из M» muted 13.

## 4. States

| State | Когда | UI |
|-------|--------|-----|
| **loading** | первый заход, `packs` ещё пуст / идёт fetch | Шапка + скелет hero (скруглённый прямоугольник) + 2 скелета PackCard. Спиннер `#FF6B8A`. Без legacy blue. |
| **empty** | каталог паков пуст (аномалия) | Hero можно скрыть. Текст «Пакеты временно недоступны» + кнопка «Обновить» ≥ 44pt. |
| **insufficient coins** | `currency < price` | Системный Alert или Bubble bottom-sheet: «Не хватает монет», цена и баланс. CTA «Понятно». Список не блокируется. |
| **opening** | после confirm до ответа сервиса | Полноэкранный/оверлей dim `rgba(42,33,80,0.45)` + карточка `#FFF7FB` с `pack-bubble` или Lottie. Повторный тап по пакам запрещён (`isOpening`). |
| **success** | пак открыт | Модалка/sheet: заголовок «Новые карты», сетка `CardItem` Bubble (амплуа без клуба), дубликаты строкой «Дубликат · +N монет». Кнопка «В коллекцию» / «Закрыть» primary ≥ 44pt. После закрытия — тихий refresh баланса и CollectionStats. |
| **error** | `success: false` / throw | Alert с текстом ошибки + «Повторить». `isOpening = false`. |

`reduce motion`: opening без pulse scale; сразу статичный пак + спиннер.

---

## 5. Touch / 390px

- CTA PackCard, чипы редкости, «Обновить», «Закрыть», confirm — **≥ 44pt** по высоте.
- Горизонтальные поля 16; между PackCard gap 12.
- На 390px не обрезать «Открыть» и цены; meta — одна строка с ellipsis.
- Планшет ≥ 600: список паков может стать 2 колонки; статистика на всю ширину контента.

---

## 6. Art brief (кратко)

- Палитра только из `chosen-bubble.md`.
- Иерархия: hero пака → баланс → прогресс альбома → чипы → список упаковок с CTA.
- Движение: pulse только на opening; success — появление карт (можно stagger 40 ms), без неона.
- Lottie `pack-opening.json` допустим, если цвета не спорят с Bubble; иначе статичный `pack-bubble.jpg` + ActivityIndicator.

## AC для @agent-frontend-rn

Проверяемые пункты реализации (код в этой задаче UX не меняется).

### `PackOpeningScreen.js`

1. Фон `#DFF6FF`. Шапка Bubble с балансом-pill; убрать дубль баланса из статистики.
2. Hero: `require('../assets/theme/pack-bubble.jpg')`, скругление ≥ 22, без звёзд на ассете.
3. States: loading / empty / insufficient / opening / success / error по таблице выше.
4. Пока `isOpening` — нельзя открыть второй пак.
5. После success — обновить currency + stats без полного размонтирования экрана.
6. Вкладка «Пакеты»: либо `headerShown: false` + своя шапка, либо согласовать с nav (без двойного «Пакеты»).

### `PackCard.js`

7. Рамка и бейдж по таблице тиров Bubble (starter→common … legendary/golden→legendary). Нет `#0066cc` / `#1E90FF` / `#32CD32` / `#FFD700` на тексте цены.
8. CTA «Открыть», primary, minHeight 44, radius pill.
9. Meta: «N карт · легенда X%»; длинное description убрать с лица карточки.
10. Декор — мячи, не звёзды. Гарантия — одна короткая строка цветом тира.

### `CollectionStats.js`

11. Компактный блок: прогресс fill `#5AD0FF` + 4 чипа ОБЫЧН/РЕДК/ЭПИК/ЛЕГЕН с токенами Bubble, minHeight 44.
12. Опционально ряд АТ/ПЗ/ЗЩ/ВР, если экран передаёт position stats.
13. Удалить/не показывать «Баланс: … монет» внутри этого компонента.
14. Пустые счётчики показывают `0`, ряд чипов всегда из четырёх редкостей.

### Регрессия / QA smoke

15. На ширине ~390: список читается, CTA не обрезаны, чипы влезают в один горизонтальный скролл или wrap без наложения.
16. Нехватка монет не зависает в opening.
17. После открытия пака числа в чипах и баланс совпадают с `PackService`.
