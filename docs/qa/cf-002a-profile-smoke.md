## Не входит в smoke

Нужна подмена `PackService` или полный каталог. Это строки 7, 9–13 и 16 в `docs/design/profile.md`, не короткий путь.

| Сценарий | Почему не smoke |
|----------|-----------------|
| Только дубликаты, без полученных карт и улучшений | Стартовый профиль так не собирается одной сессией паков |
| Каталог собран целиком | Нужен полный набор карт |
| `success: false` на первом заходе, «Повторить», сбой тихого refresh | Нужен упавший метод сервиса |
| `completionPercentage` не число, < 0 или > 100 | Сервис в обычном запуске отдаёт 0…100 |

Расхождение экрана со smoke — дефект для @agent-frontend-rn. `ProfileScreen.js` в этой задаче не менялся.
