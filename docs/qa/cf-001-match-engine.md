# CF-001 — unit-тесты match engine

Запуск из корня репозитория:

```bash
node --test game_logic/match_engine.test.js
```

`Math.random` в тестах зафиксирован на `0.5`, поэтому `randomFactor = 0` и исход определяется только разницей сил.

## Сценарий | ожидание | статус

| Сценарий | Ожидание | Статус |
|----------|----------|--------|
| Старт матча | У каждой команды 5 атак и 5 защит, тайм `first_half` | pass |
| Разница сил > 15 | `goal`, мяч в счёт | pass |
| Разница 6…15 | `dangerous_attack`, счёт 0 | pass |
| Разница −4…5 | `possession`, счёт 0 | pass |
| Разница −14…−5 | `defense_success`, счёт 0 | pass |
| Разница ≤ −15 | `counter_attack`, счёт 0 | pass |
| Атака 100 против защиты 50 | Гол, −1 атака у атакующего, −1 защита у обороняющегося | pass |
| Равные силы | `possession` | pass |
| Та же атака против заметно более сильной защиты | `counter_attack` | pass |
| Карта «Дальний удар» против «Подкат» | Обе силы 46, `possession` | pass |
| Карта только с `power: 10` | Вклад в атаку 3, в защиту 4 | pass |
| Амплуа | Атака: нападающие + полузащита; защита: защитники + полузащита + вратарь | pass |
| Матч не начат или уже завершён | Отказ, ошибка состояния | pass |
| Атаки или защиты тайма кончились | Отказ, чужой счётчик не списывается | pass |
| `finishMatch` после гола | В финальном счёте 1 гол атакующей команды | pass |

Прогон: 21 тест, 0 падений (`node --test game_logic/match_engine.test.js`).

## Баг (не чинился — зона GDD)

**Смена тайма не совпадает с лимитом «5 наборов за тайм».**

Шаги:

1. Инициализировать матч.
2. Пять раз вызвать `executeAttack` одной и той же парой команд.

Факт:

- Каждая атака прибавляет 10 минут. На пятой `matchTime` становится 50, затем сбрасывается в 45, `half` становится 2.
- Списание этой атаки затирается: `attacksLeft` и `defensesLeft` обеих команд снова 5.
- `matchState` остаётся `first_half` до `finishMatch` (значение `second_half` нигде не выставляется).
- Если команды чередуют атаки, часы доходят до 45 раньше, чем каждая потратит 5 наборов, и запас снова заполняется. Лимит 5 атак за тайм из `docs/GAME_CONCEPT.md` при этом не держится.
