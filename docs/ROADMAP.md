## Технический стек

- **Frontend**: React Native, Redux, React Navigation
- **Backend**: Node.js, Express, Socket.IO
- **База данных**: MongoDB, Redis (кэширование)
- **Хранение**: AWS S3
- **Аналитика**: Firebase, Sentry
- **Инфраструктура**: Docker, Kubernetes, AWS EC2
- **CI/CD**: GitHub Actions, Fastlane
