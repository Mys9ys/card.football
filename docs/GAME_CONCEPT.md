# Карточный Футбол - Концепция Игры

## Общее описание

Карточный футбол - это коллекционная карточная игра, в которой игроки собирают и улучшают свои команды, участвуют в матчах и турнирах. Игра доступна на iOS и Android платформах.

## Основные механики

### Типы карт

1. **Игроки** - карточки футболистов с различными амплуа:
   - Атака (форварды, нападающие)
   - Полузащита (центральные, атакующие, оборонительные полузащитники)
   - Защита (защитники, латераи)
   - Вратари

2. **Карты атаки** - специальные действия в атаке:
   - Прорыв
   - Ускорение
   - Дриблинг
   - Навес
   - Дальний удар

3. **Карты защиты** - специальные действия в защите:
   - Подкат
   - Выбивание
   - Плотное сопровождение
   - Отбор
   - Блокирование

4. **Карты расстановки** - тактические схемы:
   - 4-4-2
   - 3-5-2
   - 4-3-3
   - 5-3-2
   - 4-2-3-1

5. **Карты мотивации тренера** - психологическое влияние:
   - Поддержка
   - Выговор
   - Вдохновляющая речь
   - Тактическая замена

### Механика матча

1. Каждая команда имеет по 5 наборов для атаки и 5 наборов для защиты за тайм
2. Определяется команда, которая начинает матч первой
3. В ходе противостояния сопоставляются:
   - Набор атаки первой команды
   - Набор защиты второй команды
4. Результат взаимодействия определяется по комбинации карт и характеристик игроков

### Прогрессия и соревнования

1. **Региональные турниры** - локальные соревнования
2. **Чемпионаты** - национальные и международные турниры
3. **Лиги** - постоянные соревнования с рейтинговой системой
4. **Кубковые соревнования** - олимпийская система

## Платформы

- iOS (iPhone, iPad)
- Android (смартфоны, планшеты)

## Техническая архитектура

- Frontend: React Native (для кроссплатформенности)
- Backend: Node.js + Express
- База данных: MongoDB
- Хранение: AWS S3 (для ассетов)

## Структура проекта

```
/card.football

  /game_logic - логика игры и механики
  /assets - графические и звуковые ресурсы
```
